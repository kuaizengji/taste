# Taste

> “我不相信所谓的‘品味’是人类独有的能力，至少在审美上不应该是，我认为完全有可能通过工程方法将其解决，设计，无非是 UI、VI、PPT、海报、图片和视频这些东西，我们只需分治下去，就能让 AI 也拥有我们所谓的审美” ———— NemoArce2007(Jimmy Xu), Chairman of the Board of CPH4.AI

开源工程：把视觉 taste 写成 AI / LLM 可重复执行的约束。

进来的链接、原则和提示词按表面归档。终态是一套方法，让 AI 在每个表面上都能做出有 taste 的结果。方法写在 [`method/`](method/)，目前只有占位。

## 目录

| 目录 | 收什么 |
| --- | --- |
| [`ui/`](ui/) | 滚动、动态、动效 |
| [`vi/`](vi/) | icon、logo、识别 |
| [`slides/`](slides/) | 幻灯片模板与原则 |
| [`posters/`](posters/) | 海报模板与原则 |
| [`figures/`](figures/) | 文章正文配图 |
| [`video/`](video/) | 视频节奏与模板 |
| [`method/`](method/) | 跨表面方法。目前只有占位 |
| [`inbox/`](inbox/) | 未归类原始材料 |

分不清归哪一个表面时，先放 [`inbox/`](inbox/)。

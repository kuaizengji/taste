# 电影式官网叙事

> 按需参考 · 主题 28《电影式官网叙事》。它把作品浏览做成“进入、浏览、聚焦、查看详情”的连续过程，不是给普通页面套一层 3D。先选一个真实页面和一个核心任务，保留项目已有内容、技术栈和导航。

## 1. 什么时候用，和旧主题差在哪

适合个人作品集、创意工作室或需要让访客理解作品关系的首页：访客先看到空间中的作品，再选中一个，最后读到标题、说明和行动入口。若用户只是查表、搜索、下单或快速读长文，直接布局更有效。

[14《滚动驱动官网》](./14-scroll-driven-site.md)关注滚动进度如何编排整页段落；本主题关注作品对象的身份、镜头进出和详情状态，即使不滚动也能完成浏览。[17《空间卡片布局》](./17-spatial-card-layouts.md)解决卡片怎样排列；本主题解决选中某个真实作品后如何连续进入、停稳、返回。图片只需要查看或揭示时回看 [12《图片交互》](./12-image-interactions.md)，不要把卡片换成房间就算新方法。

## 2. 先选实现模式

| 需求 | 选择 | 边界 |
|---|---|---|
| 只需层次、景深和对象点击 | 固定视角 2.5D | 图片与 HTML 热点对齐，不称为完整 3D |
| 需要绕到背面、遮挡关系或镜头轨道 | 真 3D | 必须有可维护的几何、材质和相机状态 |
| 作品很多、任务优先或设备较弱 | 直接布局 | 保留同一内容、标题、链接和返回路径 |

先做一个展品的完整路径，再扩展数量；不要为填满场景加入无意义物件。

## 3. 状态、输入与取消

至少定义 `entrance`、`browse`、`moving-in`、`focused`、`moving-out`。镜头接近后要停稳，标题、说明、按钮放在真实 HTML 中；作品保持稳定的身份和位置，返回后仍能找到原来的对象。

鼠标、触摸和键盘都要有入口：指针悬停只负责预览，点击或 Enter 才进入；Tab 能聚焦作品，Esc、返回按钮和浏览器后退能退出详情并恢复焦点；窄屏提供直接列表或项目菜单。新输入从当前相机进度接管，不能跳回旧起点叠加动画。加载失败时显示文本和普通链接，不能让画布挡住项目入口。

## 4. 资产和技术边界

图片只能作为背景、贴图或固定视角素材，不能从一张图推导任意背面和真实遮挡。真 3D、粒子、Shader 只在项目已有能力和目标必要时采用，不把概念图当成完成实现。控制设备像素比、隐藏页面暂停渲染，并为移动端准备低成本或 HTML 方案。不要替项目预设人物、作品名、颜色或字体；资产版权、替代文本、加载占位和失败态要按真实素材确认。

## 5. 可以这样跟 AI 说

> 先检查当前项目的首页结构、作品数据、路由、设备输入和已有组件，不改成演示模板。只实现一个真实作品的入口、浏览、聚焦和详情四个状态：镜头或对象移动到目标后停稳，标题、说明和链接保持可读；点击、Enter、触摸都能进入，Esc、返回按钮和浏览器后退从当前进度退出并恢复焦点。请同时提供窄屏直接列表、资源加载失败回退、`prefers-reduced-motion` 分支和普通 HTML 链接。先交付可走通的单个展品，再说明是否需要真 3D；不要用默认人物、配色或概念图替代实际内容。

## 6. 验收

- 入口 → 浏览 → 聚焦 → 详情 → 返回可重复走通，打断移动后不会跳位或叠加。
- 键盘、触摸、鼠标均能完成核心任务，焦点可见且返回到原控件；窄屏有直接导航。
- 开关减少动态效果后立即采用静止或短过渡方案，内容和链接仍可用；调整窗口、图片加载失败或 WebGL 不可用时不丢入口。
- 验收记录区分代码运行、路径检查、视觉检查和用户确认，不把概念图或视频演示写成已上线。

## 7. 官方文档

- [Three.js PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)：核对透视相机与宽高比状态。
- [Three.js BufferGeometry](https://threejs.org/docs/pages/BufferGeometry)：需要可维护几何时核对顶点、UV 与属性。
- [MDN Pointer events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)：统一鼠标、触摸、触笔输入并处理取消。
- [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion)：为镜头移动提供减少动态分支。

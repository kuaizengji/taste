# 可探索的小房间官网

> 按需参考 · 主题 31《可探索的小房间官网》。房间只是帮助访客按语义找到项目、关于和联系入口的空间容器；它不能替代移动端导航、页面标题或真实链接。先确认项目确实需要“探索”，否则直接布局更清楚。

## 1. 选择模式，避免把图说成 3D

| 项目需求 | 模式 | 实现边界 |
|---|---|---|
| 固定视角、少量物件、轻微纵深 | 2.5D | 一张或一组对齐的房间图 + HTML 热点，不称完整 3D |
| 必须绕行、看到背面或处理遮挡 | 真 3D | 需要真实几何、相机、材质和加载失败方案 |
| 入口多、内容长或任务优先 | 直接布局 | 用列表、导航和页面层级承载同一内容 |

[17《空间卡片布局》](./17-spatial-card-layouts.md)解决卡片或记录如何排在空间里；31 解决语义物件怎样成为导航、镜头怎样接近并返回。[14《滚动驱动官网》](./14-scroll-driven-site.md)以滚动位置编排页面段落；31 的移动由选择物件和状态驱动。图片只作为固定视角素材时回看 [12《图片交互》](./12-image-interactions.md)。换一个房间、颜色或摆件不构成新方法；必须新增“访客如何找到并完成某项任务”的验证。

## 2. 状态、输入与取消

至少维护 `home`、`moving-in`、`focused`、`moving-out`，如有昼夜再维护一个明确的 `timeOfDay`。镜头接近物件后停稳，屏幕、标签和按钮是实际 HTML；点击热点、Enter 或触摸菜单进入，Esc、返回按钮和浏览器后退退出并恢复原焦点。移动中再次选择应从当前进度转向，不能叠加多个镜头动画；隐藏或失败时仍显示直接链接。

热点必须按房间图实际显示区域计算，`object-fit: contain` 产生的留白不能让点击位置漂移。键盘可见焦点、触摸可点区域和项目名称要独立于房间画面；小屏默认显示项目列表或菜单，不要求用户在一张缩小的图里找像素。昼夜切换只改变已对齐的房间、局部灯光和环境关系，不用黑色遮罩盖住内容，也不要自动循环。

## 3. 资产与技术边界

固定视角方案可用两张对齐的昼夜图和相同投影角点；热点评估要有文本、标签和替代入口。真 3D 仅在项目确实有模型、摄像机和遮挡需求时采用，单张房间图不能生成可绕行空间。优先复用项目渲染器，预加载关键资产并处理 WebGL 不可用、图片失败和低性能设备；不要替项目填入默认人物、家具、配色或虚构作品。

## 4. 可以这样跟 AI 说

> 先检查当前项目已有内容、路由和移动端入口，只把真实的项目、关于和联系内容映射到房间物件。默认先做固定视角 2.5D：热点按显示图片的实际内容区域定位，标签与按钮用可访问 HTML；进入、聚焦、返回从当前进度接管，Esc、返回和浏览器后退恢复焦点。若检测到必须绕行才说明真 3D 所需资产，不要用一张图假装。窄屏提供直接列表，减少动态效果时保留内容和链接，资源失败或 WebGL 不可用时回退到普通页面。不要加入默认人物、家具、配色或自动昼夜循环。

## 5. 验收

- 桌面和触摸都能从首页找到每个真实入口，进入、停稳、退出、重复选择和返回可走通；焦点可见且回到触发控件。
- 不同宽高、图片留白、长标题和窄屏下热点仍对齐；直接列表不被房间遮挡。
- 减少动态偏好改变时不再强制镜头移动，内容和导航仍完整；昼夜素材对齐，加载失败、WebGL 失败和图片失败都有可操作回退。
- 明确区分概念效果、可运行页面、技术检查和用户确认，不把房间演示写成真实 3D 或已发布网站。

## 6. 官方文档

- [MDN Pointer events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)：统一指针与触摸输入并处理取消。
- [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/%40media/prefers-reduced-motion)：为镜头与昼夜过渡提供减少动态方案。
- [MDN MediaQueryList change](https://developer.mozilla.org/en-US/docs/Web/API/MediaQueryList/change_event)：偏好实时变化时更新脚本状态。
- [Three.js PerspectiveCamera](https://threejs.org/docs/pages/PerspectiveCamera.html)：只有采用真 3D 时核对相机投影与宽高比。

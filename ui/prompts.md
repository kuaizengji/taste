# UI 提示词

- 提示词（原文）：Avoid unnecessary secondary labels and descriptions. Let the layout do the explaining
- 来源：https://x.com/luinlee/status/2113085361836744764
- 来源：https://x.com/ZaynHao/status/2113456751915982917
- 表面：UI。少写次要标签和说明，让版式自己解释。
- 只有当 Eyebrow 能够提供主标题未表达的分类、上下文或关键信息时才保留。优先通过字体层级、字重、间距和留白建立清晰的视觉层次，而不是依赖额外的小标题增加设计感。

## 来源：https://x.com/ZaynHao/status/2113456751915982917

3. review 界面文案，尽量使其描述符合当前界面面相的人群，容易理解但不要过于口语化，长短适合其功能场景，不要冗余和随意造词。

4. 将页面所有使用的颜色，都换成 Radix UI Colors 的颜色。同时，使用那套颜色的使用规范来优化颜色使用。

7. 尽量减少页面中的元素动画过渡效果，如果一定要添加，则考虑通常 ease-out，250ms 是个不错的基础设定。

9. 尽量减少页面出现需要用户判断才能进行的交互；必须发生时，放在用户本来就打算做选择的地方。同时，重新思考页面中包含的功能和元素，判断信息优先级，使用更有秩序的做法进行组织。

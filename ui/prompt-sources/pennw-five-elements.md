## 三种产出

先定这次要拿生成结果干什么。只能截图的，是第一种。

1. 视觉方向图。一张图片，用来讨论往哪走，一个字都改不了。跟别人讨论方向时，这一种就够。
2. 可编辑设计稿。分层文件，能改文字、颜色、间距，不能直接上线。要接着做设计，必须能导出可编辑图层。
3. 可运行代码。HTML / CSS 或前端代码，能跑、能部署，结构不一定合项目规范。要一个能点的东西，找能出代码或能发布原型的。

想要第二种，却拿到第一种，就会觉得改不动。

## 五要素

第一句话至少写清这五样。

1. 给谁用：谁在用这个界面。
2. 要干什么：他用它完成什么任务。
3. 有哪些模块：页面由哪几块组成。
4. 里面放什么：具体的内容、数据、字段。
5. 什么限制：风格、尺寸，以及先不要什么。

五样是填空，不是话术。写的时候念得出来再打字。

## 三句补丁

可以加在五要素后面。

1. 先不要 X。不写的话，它会自己堆猜你喜欢、社区、成就徽章、新手引导。
2. 内容用中文，文字贴近真实产品。不写的话，经常是占位符和假文案。
3. 保持可编辑的分层结构。后面还要改的时候用得上。

## 改细节还是重来

错的是细节还是方向，决定修还是重来。一次只改一件事。

| 看到什么 | 怎么处理 |
| --- | --- |
| 文字写错、文案想换 | 直接改，不用再生成 |
| 颜色、字体、圆角不对 | 改主题或变量，一处改全局 |
| 模块顺序不对，或少了一块 | 用提示词只说这一处，不重做整页 |
| 整体调性不对 | 重新生成，不在错的方向上修细节 |

错字、间距、颜色值是细节，改完就能用。模块缺了或顺序不对，是结构，局部改。整体不喜欢，是方向，重来。

## 生成后五条

这五条看能不能交付，不是另一套审美。五条都过，再精修。

1. 页面齐了吗。该有的页面和状态都在吗，包括空状态、加载中、报错。
2. 主操作突出吗。第一眼知道该点哪个，还是满屏一样重。
3. 层级看得懂吗。不看解释，能分出标题、正文、次要信息。
4. 内容是真实的吗。假数据、假名字、假文案换成真的。
5. 尺寸对吗。手机稿不要放大当网页用，反过来也一样。

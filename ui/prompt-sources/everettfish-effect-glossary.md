用途是告诉非专业的人这些 UI 元素叫什么。名词和一句可改的 prompt。不覆盖落地页、Hallmark、B 端、桌面 Agent 的门禁。

来源：https://mp.weixin.qq.com/s/ojAQxVHYIsANwh61zyOOgw
作者：EverettFish

想找排版，看 01—12；常用组件，看 13—24；交互和滚动，看 25—36；基础动效，看 37—48；连续展示与跟随，看 49—60；视觉材质，看 61—72；整体风格，看 73—80。

常用入口：Hover（25）、Scroll（31）、走马灯（49）、轮播（23）、Grid（01）、毛玻璃（61）。

01 网格布局 / Grid Layout
把作品区改成 Grid 网格布局，电脑端三列、手机端一列，卡片间距统一

02 弹性布局 / Flexbox
把这排标签改成 Flex 布局，间距一致，放不下就换到下一行

03 便当盒布局 / Bento Grid
把个人介绍改成 Bento Grid，简介占大格，技能、地点和联系方式放小格

04 瀑布流 / Masonry Layout
把图片收藏页改成瀑布流，保留图片比例，不要把所有图片裁成一样高

05 分屏布局 / Split-screen Layout
首页做成左右分屏，左边标题和按钮，右边作品图；手机端上下排列

06 卡片式布局 / Card Layout
每个工具做成一张卡片，包含图标、名称、两行简介和访问按钮

07 首屏主视觉 / Hero Section
首页加一个 Hero 首屏，只放一句主标题、一句说明和一个开始使用按钮

08 侧边栏 / Sidebar
文档页左侧放章节侧边栏，当前章节高亮，点击可以跳转。

09 粘性定位 / Sticky Positioning
让文章目录用 Sticky 定位，滚到顶部后停在导航栏下面，到文章结束时停止跟随。

10 固定定位 / Fixed Positioning
把帮助按钮固定在页面右下角，滚动时保持原位，别挡住正文。

11 响应式布局 / Responsive Layout
让这个页面适配手机，三列改一列，导航折叠，正文不要出现横向滚动条。

12 留白 / Whitespace
拉开标题、正文和按钮之间的距离，增加留白，但不要让同组内容散开。

13 导航栏 / Navigation Bar
顶部加导航栏，包含作品、关于、联系，当前页面对应的入口高亮。

14 下拉菜单 / Dropdown Menu
头像旁边加下拉菜单，点击显示个人资料和退出，点击外部关闭。

15 大型下拉菜单 / Mega Menu
把产品导航做成 Mega Menu，按用途分三列，每个入口配一句短说明。

16 标签页 / Tabs
把产品介绍分成概览、参数、评价三个 Tabs，点击只切换下方内容。

17 手风琴折叠面板 / Accordion
把常见问题做成手风琴，点击问题展开答案，同一时间只展开一项。

18 模态弹窗 / Modal Dialog
点击删除时打开确认弹窗，提供取消和确认；打开后键盘焦点留在弹窗内。

19 抽屉面板 / Drawer
点击筛选后，从右侧滑出一个抽屉，里面放筛选项和应用按钮。

20 悬浮提示 / Tooltip
给这个问号图标加 Tooltip，悬停或键盘聚焦时显示费用说明。

21 弹出浮层 / Popover
点击分享按钮弹出 Popover，里面放链接输入框和复制按钮。

22 轻提示 / Toast
复制成功后在右下角显示 Toast：链接已复制，两秒后自动消失。

23 轮播 / Carousel
把案例图做成轮播，每次显示一张，支持左右按钮和底部圆点，不要自动播放

24 图片灯箱 / Lightbox
点击作品缩略图打开 Lightbox，显示完整大图，支持关闭和左右切换。

25 悬停 / Hover
给作品卡片加 Hover，鼠标放上去上移 6 像素、阴影加深，移开恢复。

26 焦点状态 / Focus
给输入框和按钮加清楚的 Focus 样式，按 Tab 切换时用外圈标出当前位置。

27 按下状态 / Active / Pressed
按钮按下时缩小到 96%，松开恢复，做一个轻微的按压反馈。

28 禁用状态 / Disabled
必填项没填完时禁用提交按钮，下面提示还缺哪些内容。

29 拖放 / Drag and Drop
让任务卡片可以拖放排序，拖动时显示落点，松手后保存顺序。

30 滑动手势 / Swipe
手机端支持左右 Swipe 切换作品，上下仍然正常滚动页面。

31 滚动 / Scroll
让这个消息列表在容器内纵向滚动，输入框保持在列表下方。

32 平滑滚动 / Smooth Scroll
点击目录时 Smooth Scroll 到对应章节，并给顶部导航留出偏移量。

33 横向滚动 / Horizontal Scroll
把作品区做成横向滚动卡片，右边露出下一张的一部分，手机可以左右滑动。

34 滚动吸附 / Scroll Snap
给横向卡片区加 Scroll Snap，松手后吸附到最近的一张卡片。

35 无限滚动 / Infinite Scroll
列表快滚到底部时再加载下一批，加载中显示提示，失败时给重试按钮。

36 回到顶部 / Back to Top
往下滚两屏后显示回到顶部按钮，点击平滑返回顶部。

37 过渡 / Transition
按钮背景色变化加 200 毫秒 Transition，保持文字位置不动。

38 缓动 / Easing
面板展开用 ease-out 缓动，开始快一点，结束慢一点，总时长 300 毫秒。

39 弹簧动画 / Spring Animation
弹窗出现时加轻微 Spring 回弹，落稳后别继续晃。

40 淡入淡出 / Fade In / Fade Out
提示文字用 250 毫秒淡入，关闭时淡出，不要同时上下移动。

41 滑入滑出 / Slide In / Slide Out
侧栏从右侧 Slide In，关闭时沿原路滑出，时长 300 毫秒。

42 缩放 / Scale / Zoom
鼠标悬停时只把卡片里的图片放大到 1.05 倍，卡片外框保持不动。

43 旋转 / Rotate
展开问题时，让右边的加号旋转 45 度，变成关闭的视觉提示。

44 翻转 / Flip
点击名片后做 Flip 翻转，正面放简介，背面放联系方式。

45 交错入场 / Stagger
这四张卡片做 Stagger 入场，每张比前一张晚 80 毫秒，幅度保持一致。

46 页面转场 / Page Transition
作品列表进入详情页时加短暂淡入淡出转场，不要让用户多等一段开场动画。

47 加载指示 / Loading Indicator
生成过程中显示 Loading 圆环和正在生成，完成后换成结果内容。

48 骨架屏 / Skeleton Screen
文章加载时显示标题、封面和三行正文的骨架屏，加载完成后替换成真实内容。

49 走马灯 / Marquee
帮我把这些特别鸣谢的头像改成走马灯，匀速向左循环滚动，鼠标放上去暂停。

50 视差滚动 / Parallax
首屏背景比前景文字滚得慢一点，做轻微 Parallax，手机端减弱幅度。

51 滚动显现 / Scroll Reveal
每个章节进入视口时淡入并上移 20 像素，只播放一次。

52 滚动进度 / Scroll Progress
文章顶部加阅读进度条，滚到正文末尾时刚好填满。

53 打字机效果 / Typewriter
让首屏这句短标题逐字打出来，播完就停，不要反复删除重打。

54 文字揭示 / Text Reveal
标题按行做 Text Reveal，从下方遮罩里向上露出，保持原来的换行。

55 乱码解码 / Text Scramble
标题出现时做一次 Text Scramble，半秒内还原成完整标题，正文保持静止。

56 数字递增 / Count-up Animation
统计卡片进入视口后，数字从 0 平滑增加到接口返回的值，播完停止。

57 三维倾斜 / 3D Tilt
卡片加轻微 3D Tilt，最大倾斜 8 度，鼠标移开后回正。

58 磁吸效果 / Magnetic Effect
给主按钮加 Magnetic 效果，靠近时最多跟随 10 像素，别影响点击。

59 光标跟随 / Cursor Follow
作品列表加光标跟随预览，鼠标经过标题时显示对应图片，离开列表就隐藏。

60 运动拖尾 / Motion Trail
鼠标移动时留下一小串淡出的圆点拖尾，停止后消失，手机端关闭。

61 毛玻璃效果 / Glassmorphism
把这张浮层做成毛玻璃，背景轻微模糊，正文和按钮保持清晰。

62 渐变 / Gradient
背景用深蓝到青绿的柔和渐变，降低饱和度，保证白字清楚。

63 颗粒噪点 / Grain / Noise
给背景加非常轻的 Grain 颗粒，只影响背景，别让正文发脏。

64 模糊 / Blur
只模糊弹窗背后的页面，弹窗内容和文字不要一起变糊。

65 发光 / Glow
给主按钮加一圈很轻的蓝色外发光，别把文字也照糊。

66 路径裁切 / Clip-path
封面图先裁成一个小圆，再扩展为完整矩形，做 Clip-path 揭示。

67 遮罩 / Mask
给走马灯左右两端加渐变 Mask，让头像自然淡出，不要突然被切断。

68 扭曲 / Distortion
图片悬停时加轻微水波 Distortion，停止悬停后恢复清晰。

69 黏液融合 / Gooey Effect
让这几个圆形标签移动时有轻微 Gooey 融合，文字不要跟着变形。

70 粒子效果 / Particles
首屏背景放少量缓慢漂浮的粒子，保持低对比，不要盖住标题。

71 聚光灯效果 / Spotlight
卡片加 Spotlight，鼠标移动时出现柔和光斑，离开后熄灭。

72 倒影 / Reflection
给产品图下方加一层很淡的倒影，越往下越透明，不要像复制了一张实图。

73 极简风 / Minimalism
把首页改成极简风，只保留核心标题、作品和联系入口，用字号和留白区分层级。

74 粗野主义 / Brutalism
作品集尝试 Brutalism，使用大字、直接的链接和明显分区，同时保持易读。

75 新粗野主义 / Neobrutalism
卡片改成 Neobrutalism：粗黑描边、偏移的实色硬阴影、少量明亮底色。

76 新拟态 / Neumorphism
把控制面板做成轻度新拟态，用软阴影表现凸起，选中项要有明确颜色区分。

77 拟物风 / Skeuomorphism
音量控制做成拟物旋钮，有刻度和转动反馈，但仍支持键盘调整。

78 复古风 / Retro
做成九十年代桌面软件风格，用灰色窗口、像素图标和清楚的标题栏。

79 像素风 / Pixel Art
首页插画用像素风，边缘保持清楚的方块，不要做平滑插值。

80 字符画 / ASCII Art
把首屏装饰图改成等宽字符画，深底浅字，保留物体轮廓，正文照常显示。
